# 허들링 앱 — AI 없이 손으로 했던 작업 과정 (마지막 경험)

> `story-service.md`는 "무엇을 위한 일인지"의 기준이고, 이 문서는 "실제로 어떻게 했는지"를 정리한 것. 둘은 서로 다른 문서이며 섞지 않는다.

## 작업 순서

1. 나는 uibowl에서 경쟁사 레퍼런스를 수집한다.
2. 레퍼런스를 토대로 분석하고 우리 서비스에 반영할 부분을 가져온다.
3. 분석내용을 토대로 우리 서비스 화면 설계 문서를 구체화한다.
4. figma에 레퍼런스와 화면설계서를 반영한 ui 키스크린 2~3개를 390×844 사이즈로 그린다.
5. 내부 관계자들과 협의 후 컨셉 시안을 확정한다.
6. 컨펌된 시안을 기반으로 디자인 토큰과 컴포넌트를 제작하고, 화면 디자인에 들어간다.
7. 완성된 시안에서 토큰이나 컴포넌트가 우리 가이드에 위반된 부분이 없는지 검토한다.
