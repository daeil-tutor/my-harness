# R3 — 판단 기준 (셀 수 있는 규칙)

> 출처: docs/story-work.md "멈칫함" 지점, docs/design.md, docs/story-service.md
> 규칙 ID는 R4 SSOT·R5 게이트에서 그대로 참조한다.

## C2 — 반영 포인트 선정 (2단계)

| ID | 규칙 | 판정 |
|---|---|---|
| C2-1 | 키스크린별 반영 포인트 수 | 3 ≤ n ≤ 5 |
| C2-2 | 포인트마다 PRD 근거 번호(`\d+-\d+`) | 누락 0건 |
| C2-3 | 포인트마다 출처 `ui_url` (15개 수집본 안의 값) | 누락 0건 |
| C2-4 | MVP 제외 키워드 언급 (허들링 픽, 결제, 정산, 피드백, 구매) | 0건 |

## C4 — 키스크린 컨펌 (4단계)

| ID | 규칙 | 판정 |
|---|---|---|
| C4-1 | 프레임 크기 | 전부 390×844 |
| C4-2 | 설계서 필수 요소 → 스냅샷 레이어 이름 대조 | 누락 0건 |
| C4-3 | K2 공개 범위 옵션: 비공개 / 멤버 공개 / 판매 신청 | 3개 모두 존재 |
| C4-4 | K2 판매 신청 상태: 임시저장 / 검수 대기 / 수정 요청 / 승인됨 / 반려 | 5개 모두 존재 |
| C4-5 | K3 판매 기준 체크리스트 (PRD 6-7 8항목) | 8개 모두 존재 |
| C4-6 | K3 액션 버튼: 승인 / 수정 요청 / 반려 | 3개 모두 존재 |
